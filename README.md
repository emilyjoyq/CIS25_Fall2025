## Project Overview
This project is a digital lab notebook application written in C++ that allows users to log, track, and analyze chemical reactions. The program stores detailed reaction information, including reagents, solvent, temperature, pH, reaction duration, and user observations. It also provides the ability to save and load reaction data, enabling long-term tracking of experiments in a research lab setting.

---

## Goals
- Create an application for recording chemical reactions and unique lab conditions in experiments that is distinct from current applications.  
- Implement persistent storage so that all reaction data can be saved and reloaded for future reference.  
- Allow users to view all logged reactions and search/filter by chemical, date, or keyword in notes.  
- Enable a structured and organized approach to recording experimental data digitally, simulating a professional research lab notebook.

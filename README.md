#Decription 
This program demonstrates a menu system that gives 3 options:
- User selects 1 option by entering numbers 1-3
- If option 1: program asks for 3 numbers and outputs the largest one
- If option 2: program displays "Displaying items..."
- If option 3: program displays "Exiting..." and ends
- If the user enters a number that is outside of the menu options, the program outputs an error message

## Inventory Search Program:
- This program creates a list of 100 inventory items, each with a unique name and number
- It uses a struct named Item to store both the item's name and ID together
- When the program runs, it automatically fills the inventory with items named Item1 through Item100, with ID from 1000 to 1099
- User is asked to enter an item ID to search for
- Program uses binary search to quickly find the matching item in the list
- If the item is found, it displays the item's name & ID or tells the user it doesn't exist if item isn't found

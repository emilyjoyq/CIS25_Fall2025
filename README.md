## Diner Menu Program 
When running this program, the user can choose between steak, pasta, or pizza, and the program will also ask follow-up questions to further clarify the choices of each menu item.

1. For the steak option, it asks how you want your steak cooked 
2. For the pasta option, it asks what type of pasta is wanted
3. For the pizza option, it asks how many slices
- After each of these options, a corresponding confirmation message is printed.
4. When choosing the exit option, it ends the program with a message
